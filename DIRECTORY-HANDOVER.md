# Directory maintenance

Open the committee dashboard and choose Manage directory listings. Search the business selector or choose Add a new business. Confirm public details with the operator, tick Publish in directory and save. Untick Publish for closures. Tick the member badge only against the current ETI register. The form can restore the preceding saved version. Review location and phone before using directory information in publications.

The initial research contained 203 records. The release baseline has 134 approved listings. The original research and reasons for holding 69 entries belong in private storage. The current public payload includes approved records and public fields only. Never commit private evidence to this public repository. Previous commits and older deploys contained the original file. See release handover for the remaining privacy action.
